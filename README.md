# Habitat and Spatial Ecology Portfolio

Charlie Wiebe's habitat, fisheries and spatial ecology projects, built from public data.

**Portfolio:** https://charliewiebe.github.io/habitat-portfolio/

| Project | App | Code |
|---|---|---|
| Oregon Groundfish Habitat: lingcod, canary rockfish and sablefish habitat off Oregon, with climate, low-oxygen and fishing-rule scenarios | [Open](https://charliewiebe.github.io/habitat-portfolio/oregon-groundfish-habitat/) | [oregon-groundfish-habitat/](oregon-groundfish-habitat/) |
| Kit Fox Oregon Outlook: is there enough connected habitat for a viable kit fox population in Oregon, now and to 2100? | [Open](https://charliewiebe.github.io/habitat-portfolio/kit-fox-oregon/) | [kit-fox-oregon/](kit-fox-oregon/) |

## Layout

```
index.html                    portfolio page
assets/                       screenshots used on the portfolio page
oregon-groundfish-habitat/    app (index.html), pipeline, data, tests; see its README
kit-fox-oregon/               app (index.html), R pipeline, Shiny app, data, tests; see its README
```

Each project folder is self-contained: its `index.html` is the built app, and its README covers data, method and how to rebuild.
